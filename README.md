# Jebickson Samuel — Portfolio

A responsive, dependency-free portfolio inspired by https://fvukelic.com/. Built with HTML, CSS, and JavaScript. Source and deployment assets are in `dist/`.

## Preview

Run `npm run dev` from this directory, then visit http://127.0.0.1:5173. No dependency installation or build is required. Run `npm run check` for JavaScript syntax checks.

## Personalize

- Edit `dist/profile.js` for your name, professional title, email, toolkit, and projects.
- Edit `dist/index.html` for biography, approach, and learning copy.
- Edit `dist/styles.css` for colors, spacing, typography, and breakpoints.
- Add your project screenshots to `dist/assets/` and update each project's image path.
- The role, toolkit, biography, and learning topics are starter content; review them before sharing publicly.
- Project images, demo links, and repositories currently reference Franck Vukelic's work. They are visibly attributed samples, not claims about Jebickson's work. Replace these and remove the sample labels/attribution when adding your own projects.

## Included

Responsive navigation with current-section tracking; interactive hero dots; project category filters; expand/collapse gallery; keyboard-accessible project dialogs; learning accordions; email links and copy button; reduced-motion support; local static server with no third-party packages.

`mailto:` opens the visitor's email application. The site does not send messages or store visitor data. All sample project links go to the original reference destinations.
